# Translation glossary and protected terms

This file defines the localization rules for the English and Brazilian Portuguese versions of the PNS methodological report and analytical artifacts.

## Protected content

- Keep the names of all 27 Brazilian federative units unchanged in both languages.
- Localize only the national label: `Brasil` in PT-BR and `Brazil` in EN.
- Keep `PNS`, `PNSIBGE`, `survey`, `OMOP`, `OHDSI`, `SUS`, `IPCA`, institutional acronyms, R function names, variable codes, formulas, DOI values, and URLs unchanged.
- Keep literal Portuguese PNS response labels such as `Sim` and `Não` when they are used to match source-microdata values in executable code.
- Keep publication titles in their original language unless an official English title is available and documented.

## Numerical presentation

- PT-BR display: decimal comma and period as the thousands separator.
- EN display: decimal point and comma as the thousands separator.
- Comparisons between languages use the underlying numeric values, not localized display strings.
